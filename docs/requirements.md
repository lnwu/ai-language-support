# 需求文档：Mac 语言优化器（MVP）

## 目标
在 macOS 上提供“选中文本 + 快捷键”调用大模型 API 优化文本，并将结果替换回原文。支持任意应用输入框，支持自定义 OpenAI 兼容接口与 API Key，使用系统 Keychain 保存密钥。

## 范围与约束
- 平台：macOS 26
- 目标应用：支持 Accessibility API 的任意应用
- 优化目标：修复语法和拼写错误，尽量更简洁（默认单一目标，可在设置中切换）
- 模型接口：OpenAI 兼容 API
- 密钥存储：Keychain
- 离线策略：失败提示错误
- MVP 功能：快捷键触发 -> 优化 -> 替换原文

## 核心用户流程
1. 用户在任意应用输入框中选中待优化文字
2. 使用快捷键 CMD + E 触发优化
3. 客户端调用配置的 OpenAI 兼容 API
4. 得到优化结果并替换选中文本
5. 失败时提示错误并保留原文

## 功能需求
- 全局快捷键触发
- 读取当前选中文本并发送给模型
- 结果替换选中文本（原位替换）
- 选区右上角显示三点跳动加载标识
  - 触发后立即显示，请求结束或失败即消失
  - 最大显示时长 3 秒
  - 不提供无法定位选区的降级提示
- 菜单栏 App：点击 icon 展示菜单
  - 设置
  - 退出
- 设置页：配置 API Base、API Key、模型名、默认优化目标
- 错误提示：网络或 API 失败提示，不做离线缓存

## 非功能需求
- 安全：API Key 存储在 Keychain
- 性能：触发到替换尽量快速（目标 < 2 秒，取决于模型响应）
- 稳定性：支持的应用中稳定读取/替换选中文本
