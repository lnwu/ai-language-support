# 设计方案：Mac 语言优化器（MVP）

## 目标与范围
本方案面向 macOS 26，首期仅支持 Slack。用户在 Slack 中选中文本后，使用快捷键 CMD + E 触发优化，调用 OpenAI 兼容 API，返回结果原位替换。API Key 存储在 Keychain，默认优化目标为“修复语法和拼写错误，尽量更简洁”。

## 架构概览
菜单栏应用作为入口与状态管理，核心能力由五个模块协作：
- Hotkey Listener：全局监听 CMD + E，在 Slack 聚焦时触发。
- Selection Provider：通过 Accessibility API 获取选中内容与选区坐标。
- Overlay Renderer：在选区右上角显示三点跳动加载标识。
- LLM Client：向 OpenAI 兼容 API 发送请求并解析结果。
- Result Applier：将结果写回选中文本。

## 组件划分
1) 菜单栏应用
- 展示菜单项：设置、退出。
- 展示当前配置状态（可选）。

2) 快捷键监听
- 只在 Slack 为前台应用时触发。
- 触发后校验选区内容是否存在。

3) 选区获取
- 使用 Accessibility API 获取选区文本与屏幕坐标。
- 选区为空或不可访问时提示错误并终止流程。

4) 加载标识渲染
- 以透明悬浮层渲染三点跳动动画。
- 显示在选区右上角，不可交互。
- 最大显示时长 3 秒，若请求未完成则自动隐藏。
- 请求完成或失败时立即隐藏。
- 不提供无法定位选区的降级提示。

5) 模型调用与结果写回
- 按 OpenAI 兼容格式发送请求。
- 响应成功后替换选中文本。
- 失败时提示错误并保持原文本。

## 数据流
1. 用户选中 Slack 文本并按 CMD + E。
2. Hotkey Listener 校验 Slack 聚焦状态。
3. Selection Provider 获取选区文本与坐标。
4. Overlay Renderer 显示三点跳动标识。
5. LLM Client 发送请求并等待响应。
6. Result Applier 原位替换选中文本。
7. Overlay Renderer 隐藏标识。

## 交互与 UI
- 菜单栏 icon 点击后展示：设置、退出。
- 触发优化后，选区右上角显示三点跳动动画。
- 三点跳动为轻量提示，不阻断输入。
- 最大显示时长 3 秒；完成或失败立即消失。

## 错误处理
- 选区为空：提示错误，不发起请求。
- 无 Accessibility 权限：提示并引导开启权限。
- API 请求失败：提示错误，原文本保持不变。
- 超时或网络失败：提示错误，流程结束。

## 配置与安全
- API Key 保存于 Keychain。
- API Base、模型名、默认优化目标保存于本地配置文件。
- 设置页用于查看与更新配置。

## 测试计划
- 选区定位精度：单行、多行、不同字体与长度。
- Slack 聚焦检测正确性。
- 三点跳动显示位置与 3 秒上限。
- 请求成功后替换文本的稳定性。
- API 失败与网络断开时的提示逻辑。

## 风险与约束
- Accessibility 权限可能被用户拒绝，影响选区获取。
- Slack 更新可能影响选区坐标读取稳定性。
- 3 秒显示上限可能在网络慢时导致提示消失但请求仍在进行。
